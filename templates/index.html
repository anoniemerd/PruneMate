Cleanup options

Stopped containers Exited, dead and created containers.
Unused images All images not used by any container (not only dangling).
Unused networks Custom networks without connected containers.
Unused volumes Includes named volumes. Data is deleted permanently.
Careful: volume pruning deletes data. Every volume that isn't attached to a container is removed, including databases of stacks that are temporarily stopped. Protect important volumes with the label below, or keep this off.
Build cache Unused BuildKit / builder cache.

Protection

Skip resources with a keep label Containers, images, networks and volumes with this label are never pruned.
Example: docker volume create --label {{ config.protect_label or 'prunemate.keep' }} db_data
Only prune resources older than this. 0 = no limit. Not applied to volumes (Docker has no age filter for them).
