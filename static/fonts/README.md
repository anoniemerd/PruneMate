# Fonts

`montserrat-latin-600-normal.woff2` and `montserrat-latin-700-normal.woff2` are the Montserrat typeface
by Julieta Ulanovsky et al., distributed via [Fontsource](https://fontsource.org/fonts/montserrat),
licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).

They are self-hosted so the UI makes no external requests and works with a strict Content-Security-Policy.
